# Priomate

Priomate is a task manager for individuals and teams. This plugin connects Antigravity to your Priomate account through the remote Priomate MCP server, so you can ask about your tasks, notes, inbox, team projects and tracked time while you work.

## Requirements

- A Priomate account on the **Pro**, **Pro Student** or **Business** plan. On the Free plan, sign-in works, but every request is declined.
- On first use, Antigravity opens the browser. Sign in to Priomate and click **Allow** on the consent page.
- Antigravity currently gets **read-only** access. Nothing can be deleted.

## Included tools

| Tool | What it does |
| --- | --- |
| `tasks_overview` | Overdue tasks, tasks due today and this week, plus unread inbox entries |
| `tasks_list` | List your tasks |
| `tasks_search` | Search tasks by text |
| `tasks_get` | Full details of one task, including its checklist |
| `tags_list` | Your color tags |
| `notes_list` | Notes from your board |
| `drafts_list` | Unfinished task drafts |
| `inbox_list` | Your inbox entries |
| `projects_list` | Team projects you belong to |
| `project_get` | One team project with members and its project tasks |
| `project_messages` | Messages in a project chat |
| `time_running` | The timer that is currently running |
| `time_entries` | Your time entries for a period |
| `time_totals` | Tracked time summed up per task |
| `docs_search`, `docs_get` | The public Priomate help docs |

## Example workflows

- **Plan your day:** "What are my most important tasks today?"
- **Catch up:** "Which of my open tasks are overdue, and which have high priority?"
- **Team check-in:** "Summarize the open tasks and the latest chat messages in my project."
- **Time review:** "How much time did I track this week, and on which tasks?"
