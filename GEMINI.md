# Priomate

Priomate is a task manager (priomate.com). This extension connects to the Priomate MCP server.

- Sign in via OAuth when prompted. A Priomate Pro or Business plan is required.
- Use the Priomate tools for tasks, tags, notes, drafts, inbox, team projects, time tracking and the Priomate help docs.
- Write actions (create or update tasks, notes, time entries, project messages) may be declined depending on the client. If that happens, tell the user they can make the change in the Priomate app.
- Confirm with the user before changing or completing tasks.
